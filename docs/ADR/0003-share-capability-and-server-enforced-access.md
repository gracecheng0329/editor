# 以分享閱讀能力與服務端授權區分協作者

架構審查需要低阻力觀看，同時限制誰能修改，因此文件預設私密，owner 管理授權，editor 依身分取得編輯權，viewer 則須持有效且可撤銷的分享 token；匿名 viewer 可讀，登入後可留言。相較所有連結持有者皆可編輯或強制所有觀看者加入工作區，此模型保留分享便利性與明確的文件編輯邊界。

畫布寫入、產品資料及留言訂閱都須由服務端驗權；editor 撤權後僅在持有效分享 token 時降為 viewer，撤銷分享不影響仍有效的 owner／editor。代價是必須獨立處理 WebSocket 與留言訂閱的到期／撤權，不能只隱藏 UI 或依賴客戶端重連；留言訂閱資格的實現方式仍須在 S4 前驗證，產品規則與 60 秒上限見 [權限矩陣](../specs/001-collaborative-architecture-whiteboard.md#權限矩陣與身分轉換)。
