# 以畫布世代切換處理版本還原

同一文件允許離線修改與在線還原，單純覆寫目前快照會讓舊編輯於重連後污染還原結果，因此由 Durable Object 唯一協調還原：暫停接受寫入、可靠保存還原前快照，再原子切換畫布與有效世代，最後補寫 Postgres 索引。舊世代寫入一律拒絕，仍存活頁面的待同步內容由使用者另存新文件或明確放棄；這比靜默重播安全，也保留使用者指定的原文件還原體驗。

代價是還原成為具有持久進度的操作，必須使用穩定操作 ID 去重，區分切換前失敗、切換後索引失敗與成功回應遺失；留言與權限不隨畫布回退。SDK 世代拒寫與待同步內容保留方式仍待 G0 驗證，重試／保留政策須在 S5 前定案；完整行為見 [總規格](../specs/001-collaborative-architecture-whiteboard.md)。
