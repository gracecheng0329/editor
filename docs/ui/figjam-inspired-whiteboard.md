# FigJam 風格白板介面

建立日期：2026-10-11。這是總規格之外的本地 UI 預覽工作，不代表 G0 或 S1–S5 tickets 已完成；總規格、ADR 與雲端資料權威分工不變。

## 設計依據

實際查看使用者提供的 [FigJam 參考白板](https://www.figma.com/board/hoNIrcfZwvYj724tkCxTlY/Untitled)。參考其點陣無限畫布、左上文件浮窗、右上協作入口、底部工具列及獨立縮放控制；不複製 Figma 品牌、範本圖像或其完整功能。

介面以暖白、細邊框、低陰影與紫色操作重點呈現，搭配五種粉彩架構節點。沿用 Next.js、TypeScript、Tailwind 與 tldraw；用 tldraw 公開介面處理畫布，不新增其他同步引擎。

## 介面與互動

| 區域 | 本次提供的程式 | 與正式規格的界線 |
| --- | --- | --- |
| 左上文件浮窗 | 文件名稱、收藏、文件選單 | 本機單份文件，不是 GitHub 登入或雲端文件清單 |
| 左側元件庫 | 搜尋並新增用戶端、服務、資料庫、儲存空間、訊息佇列 | 穩定 ID 的自訂 tldraw shape；可雙擊名稱或以選取浮窗修改 |
| 無限畫布 | 架構示範、方向連線、文字、選取、移動、調整尺寸、平移與縮放 | 範例是可編輯畫布；不是遠端服務拓撲或上線狀態 |
| 底部工具列 | 選取、平移、手繪、整筆擦除、便利貼、形狀、方向連線、文字、undo／redo | 本機操作；不能當作多人 undo 與離線合併已驗證 |
| 筆畫樣式 | 顏色與粗細 | 不含像素擦除、筆畫切割或壓感 |
| 右側留言 | 本機討論串、回覆、解決／重開、物件／座標錨點與畫布留言標記 | 不含 Supabase Realtime、@提及或服務端角色驗證；範例留言明示為導覽 |
| 右側版本 | 建立命名本機里程碑、隔離唯讀預覽 | 只保存畫布 document snapshot，不含留言與工作階段；沒有自動快照或安全還原 |
| 分享視窗 | 邀請與連結權限的版面及待串接說明 | 邀請與分享按鈕停用，不產生可用 token 或假分享連結 |

使用 IndexedDB 保存本機 tldraw 畫布，其他本機介面資料保存在 localStorage。這不是正式規格的伺服器持久化或跨使用者協作；不得顯示「已雲端保存」。未串接的雲端功能在介面中明示，登入與權限不以客戶端旗標冒充。

提供鍵盤工具快捷鍵、對話框 Escape／Tab 焦點處理、窄螢幕排版與減少動態效果設定；這些仍須瀏覽器驗證，不代表已通過可及性稽核。
